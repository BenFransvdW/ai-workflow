Optional music beds. Create one sub-folder per bed (e.g. `assets/music/lofi/`) containing
tracks you have the rights to use (your own, or royalty-free with a licence that allows
monetised YouTube use). Reference it from `config.yaml` as `folder:lofi`.

By default all beds are `procedural:<mood>`, synthesised in code per video, so no
third-party audio is needed. Audio files here are gitignored.
